# AI-Group-Project

## G07 Lifting Analysis

เว็บวิเคราะห์การยกจากวิดีโอ สำหรับโครงงาน Lifting Weight Limit ของกลุ่ม G07

เลือกคลิป ใส่ส่วนสูงของผู้ยก แล้วดูจำนวนครั้ง ระยะเอื้อม ความสูงมือ และมุมร่างกายพร้อมกับวิดีโอ คลิกบนกราฟหรือรายการรอบยกเพื่อย้อนดูช่วงนั้น และดาวน์โหลดผลเป็น CSV, ZIP หรือวิดีโอ WebM

## วิธีใช้

1. เลือกวิดีโอที่เห็นผู้ยกเต็มตัว มีช่วงยืนตรงนิ่งสำหรับเทียบสเกล
2. ใส่ส่วนสูงจริง หรือกด **นำเข้าส่วนสูงจาก manifest** แล้วเลือกรหัสผู้ยก
3. กด **เริ่มวิเคราะห์** รอจนโปรแกรมสรุปผล
4. เล่นวิดีโอ ดูค่าของเฟรมที่เลือก หรือคลิกรายการรอบยกเพื่อย้อนดู
5. กด **ดาวน์โหลดผล** เพื่อเก็บข้อมูลก่อนปิดหน้าเว็บ

manifest ใช้คอลัมน์ `subject_id` และ `subject_height_cm` ถ้าผู้ยกคนเดิมมีหลายแถวจะรวมเป็นรายการเดียว ส่วนสูงของคนเดียวกันต้องตรงกัน ไฟล์นี้อ่านในเครื่องและไม่ได้ส่งขึ้นเว็บ

ค่าปรับละเอียดอยู่ใน **ตั้งค่าเพิ่มเติม** เช่น ช่วงยืนอ้างอิง ระยะเคลื่อนขั้นต่ำ และเวลายืนยันรอบ ช่องจำนวนจริงใช้เทียบผลหลังวิเคราะห์เท่านั้น ไม่ได้ใช้กำหนดจำนวนที่โปรแกรมนับ

แนะนำให้เปิดด้วย Chrome หรือ Edge และใช้ MP4 แบบ H.264 ถ้า MOV เปิดไม่ได้ให้แปลงไฟล์ก่อน การบันทึกวิดีโอพร้อมผลใช้เวลาประมาณความยาวคลิป ควรเปิดแท็บไว้ระหว่างบันทึก

## เปิดใช้งานในเครื่อง

ใช้ Node.js 22.12 ขึ้นไป

```sh
npm ci
npm run dev
```

เปิด URL ที่ขึ้นใน terminal ไม่ต้องติดตั้ง Python ครั้งแรกที่ติดตั้งต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลด dependencies และโมเดลสำเร็จรูปจาก Google

## วิธีคำนวณ

ใช้ MediaPipe Pose Landmarker Lite ตรวจข้อต่อทีละเฟรมในโหมด IMAGE จากนั้นกรองตำแหน่งที่ขาดหายและลดการสั่นของพิกัด ใช้ส่วนสูงจริงกับช่วงยืนอ้างอิงเพื่อเทียบสเกล และใช้ OpenCV solvePnP ประมาณตำแหน่งร่างกายในพิกัดกล้อง

- **ระยะเอื้อม H** วัดระยะในแนวราบจากจุดอ้างอิงใต้ข้อเท้าถึงตำแหน่งมือ
- **ความสูงมือ V** วัดระดับมือเหนือพื้นตามแกนตั้งที่ได้จากช่วงอ้างอิง
- **มุมร่างกาย** ได้แก่ มุมบิดตัวจากท่าอ้างอิง มุมก้มลำตัว และมุมเข่าซ้าย–ขวา
- **จำนวนครั้ง** ใช้การเคลื่อนของมือในแนวตั้ง เกณฑ์เริ่มต้นคือยกขึ้นอย่างน้อย 20 ซม. ลดมืออย่างน้อย 18 ซม. ก่อนเริ่มรอบถัดไป เวลายืนยัน 0.12 วินาที และระยะห่างระหว่างรอบ 0.6 วินาที โดยยืนยันว่ามือถึงระดับเอว การแยกเกณฑ์ขึ้นกับลงช่วยลดปัญหาการคืนมือที่สั่นใกล้ขอบเกณฑ์
- **น้ำหนักตามตาราง Demo** เลือกจากระดับมือและระยะเอื้อมตามตารางใน Demo ของรายวิชา

สูตรย้ายมาจาก Colab v2 และ Desktop app ของกลุ่ม โมเดลตรวจข้อต่อเป็นโมเดลสำเร็จรูป ไม่ได้ฝึกน้ำหนักโมเดลใหม่ด้วยคลิปของกลุ่ม เปอร์เซ็นต์เฟรมที่คำนวณระยะได้หมายถึงความครบของข้อมูล ไม่ใช่ความแม่นยำ มุมและระยะยังไม่มีค่าที่วัดจริงใช้เป็นคำตอบอ้างอิง

เว็บวิเคราะห์ตามอัตราเฟรมที่อ่านจาก MP4/MOV ถ้าอ่านไม่ได้จะใช้ 30 เฟรม/วินาที ซึ่งแก้ได้ในตั้งค่าเพิ่มเติม ตัวถอดรหัสและการตรวจข้อต่อในเบราว์เซอร์อาจให้ผลต่างจาก Python แม้ใช้สูตรเดียวกัน

## เปิดผลเดิมและดาวน์โหลด

ZIP ประกอบด้วย `summary.csv`, `frames.csv`, `lifts.csv`, `calibration.json`, `parameters.json` และ `web_result.json` สำหรับเปิดเส้นข้อต่อบนเว็บอีกครั้ง

ZIP ไม่รวมวิดีโอต้นฉบับ เก็บคลิปไว้คู่กัน เมื่อต้องการเปิดผลเดิมให้เลือก ZIP แล้วเลือกคลิปชื่อเดียวกับที่ใช้วิเคราะห์ เว็บเปิด CSV จากผล Colab/Desktop เดิมได้ด้วย แต่จะไม่มีเส้นข้อต่อแบบเว็บถ้าไม่มี `web_result.json`

คลิป ส่วนสูง และผลวิเคราะห์อยู่ในเครื่อง ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ และไม่ได้เก็บประวัติเมื่อปิดหรือรีเฟรชหน้า Repository นี้มีเฉพาะโค้ดและเอกสาร ไม่มีคลิป manifest หรือผลรายบุคคล

## GitHub Pages

ใน repository ไปที่ **Settings → Pages → Build and deployment** แล้วเลือก **GitHub Actions** เป็น Source

เมื่อ push เข้า `main` workflow ใน `.github/workflows/pages.yml` จะติดตั้ง dependencies ทดสอบ สร้างเว็บ แล้วเผยแพร่ Pages ลิงก์เว็บดูได้จากหน้า Actions หรือ Settings → Pages

```sh
npm test
npm run build
npm run preview
```

ไฟล์พร้อมเผยแพร่อยู่ใน `dist/` ใช้ path แบบ relative จึงเปิดใต้ชื่อ repository ได้ Runtime, WASM และโมเดลถูกเสิร์ฟจากเว็บเดียวกัน ไม่ต้องใช้ CDN ขณะวิเคราะห์ โมเดลดาวน์โหลดจาก URL ทางการของ Google ระหว่าง build และไม่เก็บไฟล์โมเดลใน Git

## โครงสร้างที่ใช้แก้ต่อ

```text
src/main.js               หน้าจอ วิดีโอ กราฟ และการนำเข้า/ส่งออก
src/engine.js             สูตรคำนวณ การเทียบสเกล และตัวนับรอบ
src/style.css             รูปแบบหน้าจอและการแสดงผลบนมือถือ
public/analysis-worker.js ตรวจข้อต่อและคำนวณแยกจากหน้าจอ
scripts/copy-runtime.mjs  เตรียม runtime และดาวน์โหลดโมเดล
tests/                    การทดสอบด้วยข้อมูลจำลอง
```

ทดสอบหน้าจอด้วย `npm run test:browser` เครื่องต้องมี Chrome ดูรายละเอียดการตรวจใน [VALIDATION.md](VALIDATION.md) และใบอนุญาต dependencies ใน [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
