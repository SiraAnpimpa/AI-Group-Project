# Interface

Inherit LiftDesk's warm white, dark green ink and restrained teal action color. Native Thai-capable sans typography, fixed readable type sizes, tabular numerals for measurements. A quiet header, narrow setup rail, and dominant results workspace. Video and synchronized measurements lead; setup and technical metadata use progressive disclosure. No folder paths or implementation credits in the main flow.

The desktop layout pairs a 272 px setup rail with the video and measurement inspector. Mobile becomes a single column, setup first, then video, measurements, chart and lift list; tables scroll within their own region. No page-wide overflow. Keyboard focus and error recovery are explicit. Busy states offer cancellation. Selecting a new clip clears the old results; rerunning the same clip retains its existing result until success.

The empty video stage explains where results will appear. Actual results replace it with the selected local video and a skeleton overlay. Clicking a lift or chart position seeks the video. This is the signature interaction: measurements, count and video remain synchronized at the inspected time. Avoid decorative animation; use short state transitions and respect reduced motion.

The Impeccable launcher was unavailable; guidance was read directly. Keep the incumbent visual system and implement the requested browser adaptation. Root agent only per the user's agent permission policy.
