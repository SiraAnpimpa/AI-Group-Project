# Analysis workspace

Mode: Operate.

Audience: G07 classmates demonstrating and reviewing a lifting-video analysis tool. Main task: analyze a single local clip, inspect the results against video, and save the result. The user explicitly selected a results-led layout and retained the light/teal identity.

First viewport: quiet project header, compact setup rail, dominant video, a synchronized measurement inspector, and a summary followed by charts. No promotional hero or repeated onboarding paragraphs. On narrow screens, stack setup, video, inspector and chart without horizontal page overflow.

Signature interaction: clicking a lift or a chart time seeks the video and updates the selected-frame measurements together. Work states: empty, video ready, detecting, calculating, cancelled, failed, complete, imported and exporting. Error messages include a recovery action. Details stay behind a tab or inline disclosure.
